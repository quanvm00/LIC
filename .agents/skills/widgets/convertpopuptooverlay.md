# Convert Popup To Overlay

- **Widget ID:** `incentro.convertpopuptooverlay.ConvertPopupToOverlay`
- **Type:** PLUGGABLEWIDGET
- **Version:** 1.2.1

## MDL Example

```sql
PLUGGABLEWIDGET 'incentro.convertpopuptooverlay.ConvertPopupToOverlay' widget1
```

## Properties

| Property | Type | Required | Default | Values / notes | Group | Description |
|----------|------|----------|---------|----------------|-------|-------------|
| `position` | enumeration | Yes | right | `top` \| `right` \| `bottom` \| `left` | General | Orientation for the overlay. |
| `size` | integer | Yes | 600 |  | General | In pixels. For horizontal overlays it's a width, for vertical it's used as height. |
| `showHeader` | boolean | Yes | true |  | General | Display the pagetitle in a header. |
| `closeButtonClass` | string | Yes | overlay-close-button |  | General | trigger visual transitions to close the overlay (does not automatically trigger on close page inside Mendix). |
| `underlayColor` | string |  |  |  | General | Set the background color for the underlay, for example: green, rgba(255, 0, 0), #BADA55. The underlay is black when not filled. |
| `closeAction` | action |  |  |  | Advanced | Custom close action for the overlay when clicking on the underlay. |
| `shouldClosePage` | boolean | Yes | false |  | Advanced | Does a button (defined by Close button class name) need to trigger the popup's 'close page' action within Mendix? Set to no if you handle this yourself. |
| `overlayStyle` | enumeration | Yes | over | `over` \| `push` | Advanced | The way that the overlay comes in. |
| `renderUnderlay` | boolean | Yes | true |  | Advanced | Render the region that can be clicked on for also closing the overlay. |
