# VTA JSON Viewer

- **Widget ID:** `vta.vtajsonviewer.VtaJsonViewer`
- **Type:** PLUGGABLEWIDGET
- **Version:** 1.0.0

## MDL Example

```sql
PLUGGABLEWIDGET 'vta.vtajsonviewer.VtaJsonViewer' widget1
```

## Properties

| Property | Type | Required | Default | Values / notes | Group | Description |
|----------|------|----------|---------|----------------|-------|-------------|
| `planJson` | attribute | Yes |  |  | Data | String attribute holding the dry-run/restore plan JSON, e.g. HistorySnapshot.DryRunPlanJson or RestoreResultJson. |
| `showFieldChips` | boolean | Yes | true |  | Display | Show the list of changed fields under each object. Renders an old-to-new diff when the plan JSON carries oldValue/newValue, otherwise falls back to a plain field-name chip list. |
| `maxFieldChips` | integer | Yes | 12 |  | Display | Maximum number of changed-field rows/chips shown per object before collapsing to a "+N" summary. Use 0 for the default. |
| `expandUnchangedFields` | boolean | Yes | false |  | Display | When the plan carries old/new values, fields the restore would not actually change are collapsed behind a toggle by default. Enable to show them expanded from the start. |
