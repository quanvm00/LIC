# VTA Date Picker

- **Widget ID:** `vta.vtadatepicker.VtaDatePicker`
- **Type:** PLUGGABLEWIDGET
- **Version:** 0.1.0

## MDL Example

```sql
PLUGGABLEWIDGET 'vta.vtadatepicker.VtaDatePicker' widget1
```

## Properties

| Property | Type | Required | Default | Values / notes | Group | Description |
|----------|------|----------|---------|----------------|-------|-------------|
| `dateAttribute` | attribute | Yes |  | on change → `onChange` | General::Data | The date being edited. A picked day is stored at 00:00 in the browser time zone. |
| `dateFormat` | string | Yes | dd/MM/yyyy |  | General::Data | Tokens d, dd, M, MM, yy, yyyy. Any other character is a separator, e.g. dd/MM/yyyy or yyyy-MM-dd. |
| `placeholder` | textTemplate |  |  |  | General::Data | Shown in the empty field. Empty: the date format. |

| `minDate` | expression |  |  |  | Range::Allowed days | Earliest allowed day, inclusive; the time of day is ignored. Empty: no lower bound. E.g. $currentObject/BudgetControl.FormMultipleRequisitionEmployeeInCharge_Form_Requisition_Event/BudgetControl.Form_Requisition_Event/StartDate |
| `maxDate` | expression |  |  |  | Range::Allowed days | Latest allowed day, inclusive; the time of day is ignored. Empty: no upper bound. |
| `disableWeekends` | boolean | Yes | false |  | Range::Allowed days | Saturdays and Sundays cannot be picked. |
| `rangeMessage` | string |  | Choose a date between {min} and {max}. |  | Range::Messages | Shown when a typed date is not allowed. Tokens: {min}, {max}. |

| `onChange` | action |  |  |  | Behaviour::Events | Runs after a new value is set by the widget. |
