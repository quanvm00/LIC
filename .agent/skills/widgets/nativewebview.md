# Web view

- **Widget ID:** `com.mendix.widget.native.webview.WebView`
- **Type:** PLUGGABLEWIDGET
- **Version:** 4.0.0

## MDL Example

```sql
PLUGGABLEWIDGET 'com.mendix.widget.native.webview.WebView' widget1
```

## Properties

| Property | Type | Required | Default | Values / notes | Group | Description |
|----------|------|----------|---------|----------------|-------|-------------|
| `url` | textTemplate |  |  |  | Data source | The URL of the web page that is loaded. |
| `content` | textTemplate |  |  |  | Data source | The HTML content to be rendered. This will precede URL |
| `onLoad` | action |  |  |  | Events | On load |
| `onError` | action |  |  |  | Events | On error |
| `onMessage` | action |  |  |  | Callback | Used to communicate from the loaded webpage to the native app trough window.ReactNativeWebView.postMessage([string]) |
| `onMessageInput` | attribute |  |  |  | Callback | The attribute where the input message will be stored. This can be used to read the input in the onMessage event. |
| `userAgent` | string |  |  |  | Advanced | A custom user agent string will be included with the request. |
| `openLinksExternally` | boolean | Yes | false |  | Advanced | If true, links embedded in source document will be opened in external browser instead of inside this widget. |
