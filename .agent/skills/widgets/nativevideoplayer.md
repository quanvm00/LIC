- **Type:** PLUGGABLEWIDGET
- **Version:** 6.0.0

## MDL Example

```sql
PLUGGABLEWIDGET 'com.mendix.widget.native.videoplayer.VideoPlayer' widget1
```

## Properties

| Property | Type | Required | Default | Values / notes | Group | Description |
|----------|------|----------|---------|----------------|-------|-------------|
| `videoUrl` | expression | Yes |  |  | General::Data source | URL of the MP4 video file that is played. |
| `autoStart` | boolean | Yes | false |  | General::Behavior | Automatically start playing the video after it loads. |
| `muted` | boolean | Yes | false |  | General::Behavior | Mute the sound of the video. |
| `loop` | boolean | Yes | false |  | General::Behavior | Repeat the video after it finishes. |
| `aspectRatio` | boolean | Yes | true |  | General::Display | Base aspect ratio on video height. If set to false, make sure to add height and width to the 'video' style property. |
| `showControls` | boolean | Yes | true |  | General::Display | Display video controls to pause, play, go fullscreen, etc. |
